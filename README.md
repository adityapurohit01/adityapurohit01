## 🚀 Selected Projects

### [Agentic Dating](https://github.com/adityapurohit01/agentic-dating)
A grounded multi-agent matchmaking system. Candidate agents build evidence-backed personas, engage in simulated conversations, retain lessons across rounds, and produce compatibility rankings.
- Multi-stage agent pipeline with persistent memory.
- MCP tools for profile, memory, ranking, and pipeline operations.
- Evaluation suite with causality, planted-truth, and ablation tests.
- Explicit mock mode to distinguish fixture-based results from live model runs.

### [Med-Le](https://github.com/adityapurohit01/med-le)
An AI-powered health and nutrition platform combining multimodal food logging, personalized diet planning, and a medical knowledge RAG assistant.
- FastAPI backend with React and TypeScript frontend.
- Qdrant-based retrieval with metadata-aware context filtering.
- Vision-enabled meal logging and nutrition analytics.

### [Hierarchical Math RAG](https://github.com/adityapurohit01/Hierarchical-Math-RAG-System)
A textbook-focused RAG system that preserves the structure of chapters, topics, examples, formulas, and figures.
- Hierarchical document parsing and knowledge graph construction.
- Hybrid retrieval and scoped example lookup.
- Smart figure retrieval enriched with vision-language descriptions.

### [MIRA](https://github.com/adityapurohit01/Mira)
An AI-based interviewer recommendation module that matches candidate resumes with interview panel expertise using NLP and relevance scoring.
